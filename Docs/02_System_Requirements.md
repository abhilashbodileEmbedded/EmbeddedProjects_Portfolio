# Functional Requirements

FR-01
The system shall blink the status LED every 500 ms.

FR-02
The system shall generate simulated sensor data.

FR-03
The logger shall print diagnostic information every second.

FR-04
The USER button interrupt shall wake a waiting task.

FR-05
The ECU shall enter WARNING state if temperature exceeds 70°C.

FR-06
The ECU shall enter FAULT state if temperature exceeds 90°C.
