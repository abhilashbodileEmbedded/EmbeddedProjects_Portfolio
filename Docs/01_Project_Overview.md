# Smart Vehicle ECU Simulator

## Objective

The objective of this project is to simulate a simplified automotive ECU using an STM32F401RE microcontroller and the FreeRTOS kernel.

The project demonstrates:

- Layered software architecture
- Task scheduling
- Queue-based communication
- Interrupt handling
- Binary semaphores
- UART CLI
- Software timers
- Fault detection
- State machine implementation

Target MCU:
STM32F401RET6

RTOS:
FreeRTOS Kernel

IDE:
STM32CubeIDE

Language:
Embedded C
