# Engineering Rules

## Rule 1

No application code inside main.c.

---

## Rule 2

One module = One responsibility.

---

## Rule 3

Every API shall have a clear purpose.

---

## Rule 4

No magic numbers.

Always use named constants.

---

## Rule 5

Static variables remain private to the module.

---

## Rule 6

Header files expose public APIs only.

---

## Rule 7

Compile without warnings.

---

## Rule 8

Commit after every completed feature.
